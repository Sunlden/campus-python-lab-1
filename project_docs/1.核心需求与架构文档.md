# 核心需求与架构文档

## 1. 项目目标
本项目旨在打造一个面向初学者的 Python 数据处理与自动化（核心围绕 Pandas、Matplotlib 和 Tkinter）交互式微课教学网站。
通过将传统的“阅读-运行代码”教学模式转化为生动、即时的“互动游戏-实时代码反馈”模式，降低学习门槛，提升学习兴趣。
核心教学内容覆盖：
- 现实校园数据（脏数据）的自动化清洗。
- 数据可视化与图表分析表达。
- 自动化处理程序的图形界面（GUI）构建与打包封装。

## 2. SPA 架构针对本项目的核心优势
本项目采用 **Vite + Vue 3 + Vue Router** 构建单页面应用（SPA），具有以下针对性优势：
- **无缝的交互体验**：各章教学和互动游戏之间的切换无需重新加载页面页面，沉浸感强。
- **状态管理**：借助 Pinia 管理学习进度、关卡得分以及代码运行上下文，实现全局状态的轻松共享。
- **与 Pyodide 完美融合**：通过 Web Worker 加载 Pyodide 提供纯前端的 Python 运行环境，SPA 架构使得在进行章节切换时无需反复初始化庞大的 WebAssembly 环境，极大提升性能和响应速度。
- **动效集成友好**：与 GSAP 的配合更为紧密，便于在路由切换和复杂交互组件上施加精细的生命周期微动效。

## 3. 技术栈
- **核心框架**：Vue 3 (Composition API) + Vite + Vue Router + Pinia。
- **UI & 样式**：Tailwind CSS（实现灵活一致的设计系统）。
- **前端动效**：GSAP。
- **代码执行**：Pyodide (WebAssembly)。
- **交互/图表库**：SortableJS/Vue.Draggable (拖拽)，ECharts (图表预览)，Blockly (积木拼装)。

## 4. 目录结构规划
以下是 `src` 目录下的核心架构规划：

```text
src/
├── assets/             # 静态资源（图标、示例数据文件、字体）
├── components/         # 公共/独立组件
│   ├── layout/         # 布局组件（Header, Sidebar, TechDashboard）
│   ├── pyodide/        # Python 运行终端交互面板组件（终端模拟器）
│   └── shared/         # 按钮、卡片、模态框等原子组件
├── views/              # 页面视图（按教学章节划分）
│   ├── Chapter1.vue    # 第一章：数据处理与自动化分析（数据清洗消消乐）
│   ├── Chapter2.vue    # 第二章：数据可视化与信息传递（可视化连连看）
│   └── Chapter3.vue    # 第三章：GUI 与程序打包（Blockly 积木生成 UI）
├── workers/            # Web Worker 脚本
│   └── pyodide.worker.js # 独立运行 Pyodide 的 Worker，避免阻塞主线程
├── store/              # 状态管理 (Pinia)
│   └── courseStore.js  # 存放当前章节、通关状态、Python 运行时状态
├── router/             # 路由配置
│   └── index.js        # Vue Router 配置
├── utils/              # 工具函数
│   ├── pythonCode.js   # 预设的 Python 校验与检查脚本
│   └── animations.js   # 封装好的 GSAP 动效预设
├── App.vue             # 根组件
└── main.js             # 入口文件
```

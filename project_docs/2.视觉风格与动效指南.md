# 视觉风格与动效指南

## 1. 视觉设计理念 (Frontend Design 原则)
基于 `frontend-design` 技能的理念，本微课网站抛弃平庸的“AI 生成感”和默认 SaaS 模板，明确走向**浅色科技感与专业效率工具**的视觉方向。
- **核心原则**：克制、清晰、层级分明。
- **情感基调**：干净、护眼、极简，像顶尖的现代代码编辑器一样消除所有干扰，使用户专注于代码逻辑与数据反馈。

## 2. 色板规范 (Color System)
- **全局背景色 (Background)**：`bg-slate-50`（极其微弱的蓝灰色调，提供冷峻、克制的科技底色）。
- **主内容面 (Surfaces)**：`bg-white`（纯白卡片），使用卡片作为承载教学内容与交互组件的主体。
- **主交互色 (Primary/Action)**：
  - **科技蓝** (`blue-600`): 用于主要的强调按钮、代码关键字高亮以及通关正确反馈。
  - **青绿色** (`teal-500`): 作为辅助反馈色，用于“清洗成功”、“连线匹配成功”的正面状态。
- **文本层级 (Typography Colors)**：
  - 主标题：`text-slate-900`
  - 正文：`text-slate-700`
  - 辅助说明/弱化文本：`text-slate-500`

## 3. 字体与排版 (Typography)
- **字体选择**：
  - 中文内容：苹方/微软雅黑/思源黑体（无衬线体），以确保极佳的阅读性。
  - 代码片段：使用 `JetBrains Mono` 或 `Fira Code` 等具有极客风格的等宽字体。
- **排版节奏**：
  - 采用清晰的模块化留白。卡片内部使用 `p-6` 或 `p-8` 的内边距。避免紧凑杂乱的堆砌布局。
  - 标题、描述与交互区严格分离，引导视线自上而下流动。

## 4. 阴影与深度 (Shadows & Depth)
- 放弃生硬的边框，采用柔和弥散阴影构建层次。
- **默认卡片**：`shadow-sm`，营造轻微悬浮感。
- **悬停/交互态 (Hover)**：提升为 `shadow-md`，辅以极为微小的 Y 轴位移（`-translate-y-0.5`）。
- **模态框/弹窗**：使用强弥散阴影 `shadow-xl`，并配合背景的玻璃态模糊（backdrop-blur）。

## 5. GSAP 动效设计与微动效 (Meaningful Motion)
动效不应是无意义的装饰，必须服务于用户反馈和教学信息传递。

- **章节切换 (路由过渡)**：
  - 不使用生硬的跳转，使用 GSAP 执行整体透明度渐现与轻微的上浮滑入动效（`y: 10, opacity: 0 -> 1`，时长 0.4s）。
- **第一章：数据清洗消消乐 (消除与正确反馈)**：
  - **消除瞬间**：采用短促有力的弹性缩小动效，元素 `scale` 先变大到 1.1 再瞬间缩小至 0，配合粒子散开的简单视觉效果，给予操作正确的强烈“爽感”。
- **第二章：连连看 (连错与连对)**：
  - **连对匹配**：卡片边缘亮起青绿色（`border-teal-500`），产生顺滑的颜色渐变，并伴随一个“点亮”波纹。
  - **连错抖动**：当左右项匹配错误时，触发经典的水平抖动动效（X 轴左右快速位移 `x: -5, 5, -4, 4`），同时边框闪烁为柔和的红色或橙色，提示错误而不产生强烈压迫感。
- **第三章：Blockly 积木组装**：
  - 积木吸附时，右侧实时代码预览区使用代码高亮块的渐隐浮现（fade-in）效果，暗示“代码是由你的操作实时生成的”。

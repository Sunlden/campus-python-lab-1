## 第一章：数据处理与自动化分析
**小节标题**：数据清洗消消乐 —— 告别手工复制粘贴！
**知识点文案**：
- **缺失数据 (NaN)**：在现实生活中，数据缺失是常态。Pandas 会自动使用 NaN (Not a Number) 来进行标准化占位。
- **清理工具箱**：
  - `isnull()`：快速排查表格中哪些位置存在缺失数据。
  - `fillna()`：填补残缺/空值，例如将未填写的社团统一填充为“暂无”。
  - `dropna()`：去除那些缺失较多且没有价值的数据。
  - `drop_duplicates()`：移除重复数据与冗余信息，全表扫描移除完全重复的数据行。

**交互提示语**：
- *初始提示*：“请将右侧的 Pandas ‘清洗工具包’拖拽到左侧有对应瑕疵的数据上。”
- *通关提示*：“太棒了！原本需要人工排查几个小时的表格，几行 Python 代码瞬间让它变得干干净净！”
- *错误反馈 (幽默)*：“哎呀，对于有 NaN 缺失值的数据，使用 drop_duplicates 去重可不顶用哦！再想想？”

## 第二章：数据可视化与信息传递
**小节标题**：可视化连连看 —— 让校园数据开口说话
**知识点文案**：
- 干净的数据并不意味着信息已经被充分理解。数据可视化就是将抽象的数据转化为直观的图形。
- **折线图 (plt.plot)**：展示数据随时间或顺序发生的变化趋势。适合观察运动员比赛过程中心率的变化。
- **柱状图 (plt.bar)**：比较不同类别之间的数据大小，看看哪个比赛项目最受欢迎。
- **饼图 (plt.pie)**：展示各部分在整体中所占的比例。一眼看清男生和女生在报名总人数中的占比。
- **散点图 (plt.scatter)**：观察两个变量之间是否存在关系。学生身高与跳远成绩之间有关系吗？

**交互提示语**：
- *初始提示*：“左侧是老师想问你的数据问题，请把它们连线到右侧最合适的图表类型上。”
- *连对反馈*：“匹配正确！柱状图确实是比较各班报名人数差异的利器。”
- *连错反馈 (幽默)*：“用饼图来展示运动员心率随时间的变化？这块饼可能会长得像齿轮一样奇怪哦。试试折线图吧！”

## 第三章：GUI 与程序打包
**小节标题**：打造“校园管家” —— 把超能力分享给他人
**知识点文案**：
- **从代码到软件**：我们已经拥有处理数据的“超能力”，但真正的创造者懂得将智慧封装成简单易用的工具。
- **GUI (图形用户界面)**：通过窗口、按钮等视觉元素，让用户可以通过鼠标点击与程序进行交互。无需关心背后的复杂代码！
- **事件驱动与回调函数**：当你点击按钮，就相当于告诉计算机：“请执行这段指令”。
- **常用组件 (Tkinter)**：
  - `Label (标签)`：用于显示文本。
  - `Button (按钮)`：用于触发一个动作（一键清洗 / 生成图表）。

**交互提示语**：
- *初始提示*：“拖拽积木块，在右侧拼装出一个美观的 Tkinter 界面。记得给按钮绑定刚才学过的清洗函数！”
- *通关提示*：“恭喜你！你不仅编写了代码，还利用 PyInstaller 的工程化思维，成功打造了属于自己的『校园管家.exe』。现在，你可以把这款软件分享给其他同学了！”
